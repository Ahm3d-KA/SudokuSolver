# Sudoku Solver 
This project solves a bunch of sudoku puzzles using different algorithms benchmarks them against each other. A clustered boxplot can be generated by the python script.
## How to run it 
1. Change directory to src/extension/
2. Run make clean then make
3. Run ../../sudoku-solver sudoku_boards.txt
4. Run python graph.py
5. Output.png is produced
